# STANDARD RUN — fuller ideation, still cheap

Read the same context as QUICK. Prefer extending existing evidence rather than restarting from zero. Only run this on request or when QUICK lacks differentiated ideas.

1. Allow 3 independent scouts (sponsor, community/problem, prior-winners/trends) with ≤5 new unique sources each. Each writes a separate brief, no messages among scouts.
2. Dedupe sources and preserve `SRC-###`; aim for 10–12 *meaningful* problems maximum.
3. Generate up to 12 genuinely different cards, not rewrites of existing ideas; preserve previous cards and IDs.
4. Critique the top 6 ONCE with the published five-label rubric (provisional equal weights). Record sponsor-specific notes separately. No rebuttals.
5. Refine only the 2–3 strongest concept pitches **once**, incorporating the most material objections. No new research unless an unresolved rule could change the winner.
6. Deliver 5 shortlisted ideas and one backup. Report changed files in ≤200 chat words. No implementation work.

Effort ceiling: don't produce long essays, browse endlessly, or create elaborate dashboards to manage the ideas.
