# Idea cards

Every selected concept receives one `I-###-slug.md` file using `TEMPLATE.md`. No `inbox/`, `candidates/`, or `archive/` folders. Status is metadata in each card and `index.md`.

A good idea card can be judged in 60 seconds and must separate verified facts from hypotheses. Target 120–180 words of substantive content per concept; enough for clear comparison, not a proposal or implementation specification.
