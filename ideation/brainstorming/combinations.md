# Combination prompts (not submitted concepts)

Use one or two prompts for each relevant, *sourced* problem:
- What friction occurs when two disciplines exchange information?
- What if the user couldn't read long text, or the input was fragmented/incomplete?
- Can the desired result be an **actionable packet** instead of a recommendation?
- What common task could an agent **finish** rather than discuss? What proof of completion exists?
- What hidden relationship between places/events/people could design reveal at a glance?
- What nonexpert view would eliminate a domain expert's translation burden?
- Could an overlooked group benefit from a mainstream technology in a non-obvious way?
- What would make an idea visually obvious with a single before/after?

Do not combine technologies merely for their novelty; each element must solve a defined problem.
