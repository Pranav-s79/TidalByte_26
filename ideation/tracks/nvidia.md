# NVIDIA track: best use of Nemotron

**Known from user:** Build an agent that is doing real work.

**Idea-screen questions:**
- What job does the agent finish?
- Is **Nemotron** responsible for meaningful reasoning/decision-making in this proposed workflow?
- Is the result tangible and checkable rather than a paragraph of advice?
- Could a judge describe the action completed in one sentence?
- Does a human retain control over consequential actions?

**Good conceptual output forms:** reconciled case packet, completed request draft, organized action queue, follow-up status, annotated source comparison, vetted handoff. These are examples, not an implementation prescription.

**Not good enough:** 'Nemotron chatbot', 'AI copilot for anything', passive content summaries with no completion criterion.

**UNKNOWN:** official mandatory API/model, judging details, proof of use, track-specific submission requirements.
